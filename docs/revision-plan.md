# VoicePaste — актуальний план

## Пріоритети

- **Critical / High:** підтверджених відкритих дефектів наразі немає.
- **CI:** підтвердити Windows і macOS product jobs реальним запуском GitHub Actions.
- **Перед релізом:** перевірити portable package на чистій Windows, ліцензії та
  спосіб підтвердження автентичності релізу. Публікація потребує окремого дозволу.

## Обмеження

- Не змінювати погоджений focus/paste fallback. Автоматичне завантаження моделі та
  ручний retry працюють без confirmation; повідомлення про помилки зберігаються.
- Не зупиняти застосунок чи запис і не втрачати Settings drafts, prompts або дані.
- Не завантажувати моделі, не встановлювати SDK і не публікувати реліз без дозволу.
